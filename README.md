# Negin World 🪐

یه نقشه‌ی کهکشانی (mind map شعاعی) با HTML/CSS/JS ساده، بدون هیچ کتابخونه‌ای.

## فایل‌ها
- `index.html` : صفحه + متن راهنمای رمز (`NW_CONFIG.hint`)
- `style.css` / `app.js` : ظاهر و منطق
- `data.enc.js` : همه‌ی محتوا (شاخه‌ها، عکس‌ها، استیکرها) که با رمز AES-GCM رمزنگاری شده
- `fonts/` : فونت وزیرمتن و Great Vibes (لوکال، بدون نیاز به گوگل)

## دیدن روی کامپیوتر
`index.html` رو مستقیم با مرورگر باز کن. اگه مرورگر اذیت کرد، تو همین پوشه بزن:
`python -m http.server` و برو `http://localhost:8000`

## حالت ویرایش
آخر آدرس `?edit` بذار، مثلاً `.../index.html?edit`
- روی هر شاخه بزن تا فرم ویرایشش باز شه (عنوان، ایموجی، رنگ، توضیح، عکس، استیکر، لینک آهنگ…)
- «+ شاخه‌ی جدید» زیر شاخه‌ای که انتخاب کردی یه شاخه اضافه می‌کنه
- تغییرها خودکار روی همون مرورگر ذخیره می‌شن
- برای اینکه روی سایت اصلی بیاد: «💾 خروجی برای گیت‌هاب» ← فایل `data.enc.js` جدید رو جایگزین قبلی کن
- از همون پنجره می‌شه رمز رو هم عوض کرد

## انتشار روی GitHub Pages
1. یه ریپوی جدید بساز و همه‌ی فایل‌های این پوشه رو آپلود کن
2. Settings ← Pages ← Source: `Deploy from a branch` ← `main` / `root` ← Save
3. چند دقیقه بعد سایت روی `https://USERNAME.github.io/REPO/` بالا میاد
